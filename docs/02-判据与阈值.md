# 02 — 判据与阈值

## 1. 唯一被判的量：`c_rms`

```
c_rms = 128 × 10^(noise_dBFS / 20)
```

`noise_dBFS` 是观测源给的底噪估计，`c_rms` 是换算成 **8 bit 满量程的 RMS 码值**（"守卫标度"）。
可行域：

```
C_MIN = 1.3      下界：量化分辨率不足
C_MAX = 20.0     上界：过驱动，逼近削波悬崖
```

**对空情不敏感**是这套判据成立的前提：`noise` 是底噪估计，不是信号强度。
实测 `strong_signals` 从 389 涨到 873 时，`noise` 仍稳在 −22.0 ~ −21.7 dBFS。

## 2. 下界 1.3：量化台阶 / σ ≈ 1 的拐点

**确定性回放**（同一段真实 UC8 采样，只改有效量化级数，不动任何其它变量）：

| step/σ | 报文数 | 与满精度逐条重叠 |
|---|---|---|
| ≤0.74 | 32 | **1.000** |
| 1.12 | — | 掉 16% |
| 3.16 | — | 掉 50% |
| 17.4 | 0 | 归零 |

⇒ 拐点在 step/σ ≈ 0.74–1.12 之间，`c = 1.3` 落在刚过拐点的位置。

**真机侧独立确认**（两机多档扫描，`python tools/build_state_table.py` 可复算）：

| 状态 | c 区间 | 样本来源 |
|---|---|---|
| 健康工作点 | **2.93 ~ 11.67** | D84@`0x0a` 2.93–3.33（n=48）、D85@`0x11` 10.52–11.67（n=45）、CONVA@`0x11` 10.17–10.52（n=52） |
| AGC 压缩态 | **0.71 ~ 0.87** | D84 0.71（n=145）、D85 0.79–0.81（n=197）、CONVA 0.80–0.87（n=149）、CONVB 0.85–0.86（n=139） |

1.3 把两组**干净分开**，中间无重叠（健康态最低 2.93，压缩态最高 0.87，相差 3.4 倍）。

> 注：CONVB 的 BASE 段 `c` 为 0.84–2.61，是 `0x0a` 低码位 + 弱空情下的读数，
> 其下限已贴近 `C_MIN`，该段只用于 `c` 分布，不计入对照。

## 3. 上界 20：悬崖的一半

实测 `c ≥ 40` 报文**全灭**，`0x13 = 0x1c` 是悬崖码。取 40 的一半 = **20**，
即留 **6 dB** 余量（1 码 = 1.55 dB）。

两机健康工作点（`c ≈ 3.1` / `c ≈ 11.7`）都远低于 20 ⇒ 常态绝不误动；
真过驱动（AGC 接管后实测 `c = 38.66`）必触发。

## 4. 1 码 = 1.55 dB

实测 `0x0a`（−38.9 dBFS）→ `0x12`（−26.5 dBFS）：8 码 / 12.4 dB。
开路链路独立复算得 1.743 dB/码，本判据取保守值 **1.55 dB/码**（算出的步长偏大，
宁可多降一格也不欠降）。

## 5. `peak` 不是削波判据

`.85` 健康态的 `peak` 就是 **−0.8 dBFS**（由过顶航班决定），
拿 `peak` 当削波门限会**常态误触发**。

`peak` 只做兜底：`peak ≥ SAT_LIMIT_DBFS = −0.2` 时固定降 2 格。
升档也**不能**用 `peak` 余量当门限 —— `peak` 是空情量，安静时段很低、看起来余量充足，
守卫会误升码，等航班来了正好撞 0 dBFS。

## 6. 两个都叫"码值"的标度（勿混用）

| 标度 | 定义 | 用在哪 |
|---|---|---|
| **守卫标度** | `c = 128 × 10^(noise/20)` | 判据 `C_MIN`/`C_MAX`、日志 `c=`、所有阈值 |
| **真实 ADC 码值** | 按观测源换算 | 只在跨口径比较时用 |

换算关系：

- **tee 源**（`tee_power` 的 `mean_dbfs`，单分量 RMS）的 `c` **就是**真实码值；
- **stats 源**（`stats.json` 的 `noise`）的 `c` **÷1.24** 才是真实码值。

依据：`stats.c:535` 取的是 I²+Q² 的**功率**均值，比单分量高 3 dB，
再扣掉已解调信号的功率（`demod_2400.c:503`）。理论上限 `10log10(2) = 3.04 dB`。

**六轮标定**（`data/标度标定_20261025/`，两机同码、逐轮对照单分量真值）：

| 轮 | stats.noise | 单分量 dB（功率均值） | 偏移 |
|---|---|---|---|
| 1 | −28.9 | −30.53 | +1.63 |
| 2 | −28.4 | −31.23 | +2.83 |
| 3 | −27.7 | −29.08 | +1.38 |
| 4 | −27.6 | −28.53 | +0.93 |
| 5 | −28.2 | −30.46 | +2.26 |
| 6 | −28.2 | −30.26 | +2.06 |

- 偏移中位 **+1.84 dB**，范围 +0.93 ~ +2.83（n=6），**0/6 超过理论上限 +3.04**；
- 标度比中位 **1.236×**，区间 1.114–1.386×；
- 同机同码的两种拓扑实测比值：`.84` 1.39×、`.85` 1.16× —— 与六轮标定同向同量级。

⚠ **比值逐机不同**（强信号一侧更接近 1.42）⇒ 不能用一个常数跨机换算，
只能按"stats 口径 ≈ 真实码值 / 1.24"做量级修正。

## 7. 两种观测源的物理窗口不等价

同一阈值在两种观测源下对应的真实码值窗口不同：

| 观测源 | `--mode` | 日志标记 | 真实码值窗口 |
|---|---|---|---|
| `stats.json` `last1min.local.noise` | `readsb`（默认） | `src=stats` | **1.05 ~ 16.1** |
| `tee_power` `mean_dbfs` | `s1090` | `src=tee` | **1.3 ~ 20** |

现工作点真值 ≈ 4.0，两端余量 5–6 dB ⇒ 阈值与余量匹配。
**收紧 `C_MAX` 或抬高 `C_MIN` 之前必须先统一观测源口径**，否则等于悄悄改了判据。

`tee` 源取 **`mean_dbfs`**（子块功率均值）：与 readsb 口径同源，
同码同机对照 readsb `−27.7` / tee `mean −27.84`，残差 0.14 dB。
`p50_dbfs` 取"最安静子块"，与判据口径差 2–7 dB 且随空情漂（同码两分钟 4.4 dB），
不作判据，仅作观察。

## 8. 门禁：什么时候**不**判工况

判据只在稳态下有效。三个门禁按顺序短路：

| 门禁 | 条件 | 理由 |
|---|---|---|
| 收敛 | 最近 `STABLE_N = 5` 个样本（75 s）的 `c_rms` 极差 ≤ `STABLE_DB = 3.0` dB | `noise` 是 60 s 滑动窗 + 慢收敛估计器，扰动后读数会漂几十秒。实测 readsb 重启后 `c = 51→42→32→29`，此刻的"过驱动"是暂态不是工况 |
| SETTLE | 距上次写入 ≥ `SETTLE_S = 70 s` | 写入到噪声稳定至少要覆盖一个完整窗口 |
| 写间隔 | 两次写 ≥ `MIN_WRITE_GAP_S = 15 s` | 第三方（readsb 启动序列）可能连续写好几次 |
| 动作退避 | 300 s 窗内动作 ≤ `MAX_ACTIONS_PER_WINDOW = 4` | 防第三方持续抢写导致空转 |

取 5 样本（75 s）：暂态是**缓慢**收敛的，样本数必须覆盖整个收敛过程。

## 9. 动作不对称（由代价决定）

| 方向 | 规则 | 原因 |
|---|---|---|
| 降档 | 按超出量算格数 `round(20·log10(c/tgt)/1.55)`，目标 `tgt = sqrt(C_MIN·C_MAX) = 5.1`；地板 `0x08` | 降过头是缓坡：量化噪声 `(1/12)/c²` 的总损失上限 **≈0.166 dB**（出现在 `c≈1.46`），代价可逆 |
| 升档 | **一格一格**，天花板 `CODE_RAISE_MAX = 0x18` | 升过头是悬崖：`c ≥ 40` 报文全灭 |

> 两个不同量纲的数：**1.55 dB/码** 是 IF 增益步长；**0.166 dB** 是降档过头的
> 量化噪声总损失上限，与码数无关。

降档目标取域的**几何中点**（5.1 码）而不是上界：上下都留余量，避免
"降过头 → 一格一格升回来"的振荡。

`CODE_RAISE_MAX = 0x18`：距实测悬崖码 `0x1c` 还有 4 格 ≈ 6.2 dB。

两者都**与机器无关**，由常量算出，不查任何逐机表 —— 未知 FC0013 上也能自行收敛到域内。

## 10. 冷启动默认码 `0x0E`

未知 FC0013、且 `0x13` 读不回时用。推导（开路链路实测，可复算）：

| 码 | 开路自身底噪（码） | 与 `C_MIN = 1.3` |
|---|---|---|
| `0x0a` | 0.736 | **低于** ⇒ 一定欠驱动 |
| `0x0d` | 1.26 | 临界，无余量 |
| `0x0e` | **1.50** | **过，余量 15%**，且距上界还有 14 格 |

⇒ 取 `0x0e`：即便天线开路、外部噪声为零也不欠驱动。

起点码解析优先级：**显式 `--cal` > 启动读一次 `0x13` > `DEFAULT_CODE`**。
永不返回 None，也**不以"未知机器"拒绝启动**。
