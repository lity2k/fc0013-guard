## 2. 三种实验设计

### 2.1 交叉注入（测**收益**）

两机同时、2×2 交叉：每段一台"守卫 ON"、另一台"守卫 OFF"，下一段角色互换。

- **A 段（无扰动）**：两台工作点都在域内 ⇒ 测共存开销，应无差别；
- **B 段（注入 AGC）**：对 OFF 臂发 `agcon`（第三方 AGC 接管）⇒ 人为制造越界，
  看 ON 臂的守卫能否纠正，以及 OFF 臂会烂到什么程度。

交叉消机器偏置：效应 = (正向 + 反向)/2。
每臂 12 min，稳态分析跳过前 **240 s**（`noise` 是 60 s 级累加平均，注入后要等收敛）。

阶段表在 `phases.jsonl`（每阶段每机一条：`phase/host/role/t0/t1/code/inject`），
采样在 `xo_84.csv` / `xo_85.csv`（20 s/行，append 跨阶段不断）。

### 2.2 背靠背四组合（测**共存开销**）

**四组合 × 两向** 背靠背（`R` = readsb 直采拓扑，`S` = s1090 管道拓扑），
消除机器差异与相位顺序的影响：

| 对 | 组合 |
|---|---|
| P1 | R-on vs R-off |
| P2 | R-off vs S-off |
| P3 | R-off vs S-on |
| P4 | R-on vs S-off |
| P5 | R-on vs S-on |
| P6 | S-off vs S-on |
| Z | R-on vs R-off（**重复 P1**，隔 2.5 h，用于校重复性） |

一轮 **14 相位 × 10 min**，两机同时采样。

**关键机理**：14 个守卫 ON 相位里芯片**一次没写**（`fc0013=未访问` 672/678），
所以这个实验测的是**进程在跑的代价**，不是纠正收益。
守卫效应 ≈ 0 属机理预期 —— 收益由 2.1 的注入对照测量。

### 2.3 生产态交替直测（测**真实收益**，最硬的证据）

不做注入、不动拓扑，就在生产机上：

1. 先读寄存器确认 AGC 态（`0x0d=01`）；
2. A 段 60 s 记 `msgs1min` 首尾差；
3. `--pin CODE` 钉码（`0x0d=09`）；
4. B 段 60 s 同上；
5. 重复 A/B 一轮。

四段 316 s 完成，两机同时跑。A 臂的 AGC 是**芯片自己重新接管**的真实状态，
不是实验者"造假"的越界 —— 这是最贴近生产的对照。

## 3. 取数注意（读表口径）

1. **SE 取 `decompose.md`**：按**增量切块**（块之和严格等于整窗），块均值与整窗一致到 0.23 pp。
   `xover_stats.md` 的亚窗 SE 按"块内首尾点"切块，每块只覆盖 100 s 且漏掉窗口两端，
   块均值与整窗差 2.6 pp ⇒ 不作不确定度估计。
2. **`valid/s` 与 `msg/s` 恒等**（两拓扑都一样）⇒ `valid` 在本 harness 里不提供额外信息。
   判收益看 `msg/s`。
3. **`pos/msg ≈ 6%` 是结构性的**（位置报文占全部报文 5.6–7.9%）⇒ `pos` 的噪声天然是
   `msg` 的 2–3 倍。
4. **`c` 的口径随观测源变**：R 拓扑取 `stats.noise`、S 拓扑取 `tee` 的 `mean_dbfs`，
   同一工作点两者差 **1.16–1.39×**（`.84` 1.39 / `.85` 1.16）。跨拓扑比 `c` 前先换算（见 02 §6）。
5. **绝对速率不平稳**：同机 6 分钟内块间极差可达 **32 msg/s**。
   2% 量级的效应只能靠**背靠背 + 成对**测量；跨对比较不可比
   （`decompose.md §3`：机器偏置 b 在 −14.8% ~ −4.3% 之间摆）。
6. **`strong_signals` 不是判据量**，只作现场描述。
