# 06 — 验收与已知限制

## 1. 改代码后的回归门禁（三条，全过才算完）

### 1.1 离线回归

```bash
python tools/replay_guard.py
```

必须 **`场景通过 31/31 ；回放无误动作=是`**。

它覆盖五组：判据边界（A）、真实寄存器轨迹回放（B）、动作选择（C）、
I²C 传输层离线自检（D，假 libusb，核对控制传输序列）、普适性（E）、观测源（F）。
D 组会验证"写一次 `[reg,val]` 两字节、无拆分"，E 组会验证"无 `--cal` + 通道不可用 ⇒
用默认码、不拒绝启动"。

### 1.2 真机 I²C 自检

```bash
python3 fc0013_guard.py --selftest 20
```

必须 `ok=20 fail=0 first_try=20`。`ok < 20` ⇒ I²C 链路有问题，不许上线。

### 1.3 长观测

至少一台机器跑满 **90 min**，确认稳态全是 `fc0013=未访问`、无谓写 0 次。

```bash
python tools/soak_guard.py --minutes 90 --poll 30      # 先把 tools/soak_probe.py 传到 /tmp
```

## 2. 生产验收指标

| 项 | 判据 |
|---|---|
| 服务状态 | `systemctl is-active fc0013-guard` = `active`，且 `BindsTo` 生效（readsb 重启后守卫跟随） |
| 工作点 | 日志 `c=` 在 **[1.3, 20]** 内，`越界率 0%` |
| 零打扰 | 稳态下 `fc0013=未访问` 占比 **>99%**（实测 99.1% / 99.4%） |
| 收益 | 生产态交替直测 ≥ **2×**（实测 4.25× / 5.77×） |
| 共存开销 | 守卫 ON/OFF 的 msg/s 效应 **\|Δ\| ≤ 2%** |
| 纠正能力 | 注入 AGC 后 ≤ **120 s** 落回域内（实测 86–117 s） |

验收用的现场命令与取数方式见 `docs/05-安装与运维.md`、`docs/04-数据与实验.md`。

## 3. 已知限制（明确不做的）

| # | 限制 | 说明 |
|---|---|---|
| L1 | 只适用 **RTL2832U + FC0013** | 其它调谐器的寄存器语义不同，不可移植 |
| L2 | 只保证**在域内**，不追求"最优灵敏度" | 工作点最优搜索的收益硬上限约 0.3 dB，远小于越界的代价 ⇒ 不部署连续追踪器 |
| L3 | AGC 自选工作点若**仍在域内**，守卫不纠正 | 实测 `0x13=0x1c` 时 `c=7.4`，在域内 ⇒ 不动。生产态要靠开机 `--pin <码>` 强制对齐 |
| L4 | 芯片回默认态时守卫不介入 | 开机 / USB 重新枚举后核对日志 `code=`，不符则 `--pin`（05 §5） |
| L5 | 两种观测源的物理窗口不等价 | stats [1.05, 16.1] / tee [1.3, 20]（真实码值）。阈值不为此调整，但**收紧阈值前必须先统一口径** |
| L6 | 轻度过驱不介入 | `peak` 贴顶 + `strong > 0` 但 `c` 仍在域内时不动作（`peak` 只作 −0.2 dBFS 饱和兜底）。这是刻意取舍：`peak` 是空情量，拿它当判据会常态误触发 |
| L7 | 跨机只能按 `c_rms` 对齐，不能按 `0x13` 码 | 同码跨件差 **2–3 dB**（`.85` 同码比 `.84` 高约 2.3 dB）⇒ 逐机标定，码写进 `deployed.json` |
| L8 | s1090 形态不做进程内自愈 | 管道任一环断开 ⇒ 退出(3)，重启交给 systemd。进程内自愈会在设备半死时反复抢设备 |
| L9 | 与 `fc_daemon watch` 不可同时跑 | 两者抢同一组寄存器，互相覆盖 |
| L10 | 卸载不改芯片状态 | `0x0d` 仍停在 `09`（AGC 关）。恢复出厂行为需手工写 `0x01` |

## 4. 判据变更的额外约束

任何改动 `C_MIN` / `C_MAX` / `DB_PER_CODE` / `CODE_RAISE_MAX` 的提交，
必须同时给出：

1. `tools/replay_guard.py` 全绿；
2. 至少一条**新的实测锚点**（真机 `c` 与报文率的对应关系），不能只靠推算；
3. 若改的是观测源口径，须先做 ≥3 轮 `stats` vs 单分量对照（做法见 `data/标度标定_20261025/README.md`）。

**跨口径的数字必须在同一轮实验里同时采**：跨轮次拼接会引入标度偏移，
使换算系数整体偏 1.7 dB 以上。
